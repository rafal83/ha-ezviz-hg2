# Contributing

Contributions are welcome through GitHub pull requests.

## Development

1. Fork and clone the repository.
2. Copy `custom_components/ezviz_hg2` into a Home Assistant development configuration.
3. Keep changes focused and do not include credentials, tokens, serial numbers, or diagnostics containing personal data.
4. Run the validation workflows before requesting review.

## Pull requests

- Explain the user-visible behavior and supported device or firmware.
- Include validation steps.
- Update `README.md` when behavior or requirements change.
- Do not add speculative device commands. Actions must be confirmed by an EZVIZ product profile or application behavior.

## Security

Do not report credential or token exposure in a public issue. Follow `SECURITY.md` instead.
